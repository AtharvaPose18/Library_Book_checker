# Library Book Availability Checker
A simple Java program that checks whether a book is available in a predefined list of library books.

## Features
- Searches for a book by name
- Displays whether the book is available
- Ignores uppercase and lowercase differences
- Stops searching when the book is found

## Technologies Used
- Java
- Scanner class
- Arrays
- For loop
- If-else statements
- String methods

## How to Run
1. Download LibraryBookChecker.java
2. Open a terminal in the folder containing the file.
3. Compile the program:
   javac LibraryBookChecker.java
  
4. Run the program:
   java LibraryBookChecker

## Example Output
Enter book name to search: Java Programming
Book is available in the library.

This project helps practise arrays, linear searching, loops, Boolean variables, string comparison, and conditional statements.
